Instructions de conversion automatique des vues CRUD vers le format pcoded :

1. Remplacer la structure container-fluid vers pcoded-main-container :

AVANT :
<div class="container-fluid">
    <div class="d-sm-flex align-items-center justify-content-between mb-4">
        <h1 class="h3 mb-0 text-gray-800">

APRÈS :
<div class="pcoded-main-container">
    <div class="pcoded-content">
        <div class="page-header">
            <div class="page-block">
                <div class="row align-items-center">
                    <div class="col-md-12">
                        <div class="page-header-title">
                            <h5 class="m-b-10">

2. Convertir breadcrumb :

AVANT :
<nav aria-label="breadcrumb">
    <ol class="breadcrumb">
        <li class="breadcrumb-item"><a href="{{ route('dashboard') }}">Tableau de Bord</a></li>

APRÈS :
<ul class="breadcrumb">
    <li class="breadcrumb-item"><a href="{{ route('dashboard') }}"><i class="feather icon-home"></i></a></li>

3. Convertir cartes :

AVANT :
<div class="card shadow mb-4">
    <div class="card-header py-3 d-flex flex-row align-items-center justify-content-between">
        <h6 class="m-0 font-weight-bold text-primary">

APRÈS :
<div class="row">
    <div class="col-xl-12">
        <div class="card">
            <div class="card-header">
                <h5>

4. Convertir icônes FontAwesome vers Feather :
- fas fa-eye → feather icon-eye
- fas fa-edit → feather icon-edit
- fas fa-trash → feather icon-trash-2
- fas fa-plus → feather icon-plus
- fas fa-home → feather icon-home
- fas fa-truck → feather icon-truck
- fas fa-building → feather icon-home

5. Convertir les boutons d'actions :

AVANT :
<a href="" class="btn btn-info btn-sm">

APRÈS :
<a href="" class="btn btn-sm btn-outline-primary">

6. Ajouter fermeture pcoded en fin de fichier :
</div>
</div>
